# typerclass: Predicts Types of Variables

Predicts variable types (nominal, ordinal, scale) from empirical
distributions and observed values. Provides probabilistic class
estimates for numeric variables and deterministic nominal classification
for non-numeric types. Includes sample survey data and labels for
demonstration.
