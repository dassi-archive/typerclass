# Labels for Labour Force Survey Italy 2013

Variable metadata and labels associated with `lfs_it_2013`.

## Usage

``` r
lfs_it_2013_labels
```

## Format

A tibble with the following columns:

- var:

  Variable name

- value:

  Code value

- label:

  Label description

- lang:

  Language

- type:

  Variable type

- weight:

  Weight variable flag

- missing:

  Missing value flag
